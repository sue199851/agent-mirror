# confirm 出题样例 · LLM 现场生成（每轮不同）

> 这些题目由 LLM 基于「夜航员」合成人设的真实统计特征现场生成（`confirm --mode llm`）。
> **LLM 出题没有固定题库**：题目贴合当事人自己的项目、时段和行为特征，
> 每次运行都不同；下面是同一人设连续两轮的实际输出——六道题零重复，
> 且第二轮自动跳过第一轮已答维度（O1/C1/O2 不再出证据题）。
> 无 LLM key 时自动降级为固定题库（`frameworks/personality/sjt_bank.yaml`），功能完整。
> **双域出题**：性格域 votes 投 BFAS 维度；职业域 votes 投霍兰德六型（RIASEC），
> 题面测的是任务/项目/环境选择（兴趣框架），不是能力。

**Q2 [情景]** 你让 autoblog 生成的第三篇推文又被平台判了“低质内容”，已经重试两次。凌晨一点半，你：

## 设计说明

- **题型分工**：LLM 只写 SJT 情景题（场景创作是它擅长的）；证据确认题和盲区题由代码确定性生成——题面里的指标名/数值全部来自真实面板，经 LLM 手有幻觉数字风险
- **多样性来源**：LLM 拿到的是当事人的画像特征（项目分布、深夜比、挫败密度、追问率），不是模板——所以题面里的“第 47 版音色”“凌晨 1:34”“四个项目同时炸”全部由真实统计特征触发
- **出题自适应**：每轮读取 calibration.yaml，confirmed/stated/discounted 的维度不再出题，缺什么补什么
- **答案去向**：SJT 选项投票给 1~3 个 BFAS 维度（累计制）；证据题确认/否认（否认可注明情境性或盲区）；盲区题成为该维度的人工证据——全部回写 calibration.yaml，影响下次 analyze
